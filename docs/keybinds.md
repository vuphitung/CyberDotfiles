# Keybinds — CyberTung

> Danh sách đầy đủ và luôn cập nhật: nhấn `Super + F1` trong Hyprland.

## Apps
| Phím | Lệnh |
|---|---|
| Super + Q | kitty |
| Super + E | nautilus |
| Super + G | google-chrome-stable |
| Super + Space | rofi -show drun |
