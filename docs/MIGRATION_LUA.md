# Hướng Dẫn Chuyển Đổi Sang Hyprland 0.57.2 Lua Native (`MIGRATION_LUA.md`)

Tài liệu này mô tả chi tiết cách chuyển đổi toàn bộ cấu hình từ Hyprlang cũ (`config/hypr/hyprland.conf`) sang kiến trúc Lua Native (`config/hypr/hyprland.lua` và `config/hypr/modules/*.lua`) dựa trên tài liệu chính thức của Hyprland 0.57.2.

## 1. Cơ Chế Nạp Cấu Hình Trên Hyprland 0.57.2

Theo [Hyprland Wiki: Core](https://wiki.hypr.land/configuring/core/):
- Đường dẫn cấu hình mặc định của Hyprland 0.57.2 là `$XDG_CONFIG_HOME/hypr/hyprland.lua` (`~/.config/hypr/hyprland.lua`).
- Khi `hyprland.lua` tồn tại, Hyprland **chỉ nạp `hyprland.lua`** và bỏ qua `hyprland.conf`.
- Không sử dụng dòng `hl.config({ autogenerated = true })` để tắt thanh cảnh báo màu vàng ở đầu màn hình.
- Các module con được đặt trong `config/hypr/modules/` và nạp từ `hyprland.lua` qua `require("modules.init")`.

## 2. Bảng Ánh Xạ API Từ Hyprlang (`.conf`) Sang Lua Native (`.lua`)

| Chức năng | Cú pháp Hyprlang cũ (`hyprland.conf`) | Cú pháp Lua Native Hyprland 0.57.2 (`hyprland.lua`) | Tài liệu tham chiếu |
| :--- | :--- | :--- | :--- |
| **Màn hình (Monitor)** | `monitor = eDP-1, 2560x1440@60, 0x0, 1.25` | `hl.monitor({ output = "eDP-1", mode = "2560x1440@60", position = "0x0", scale = 1.25 })` | [Monitors Wiki](https://wiki.hypr.land/configuring/core/monitors/) |
| **Màn hình dự phòng** | `monitor = , preferred, auto, 1` | `hl.monitor({ output = "", mode = "preferred", position = "auto", scale = 1.0 })` | [Monitors Wiki](https://wiki.hypr.land/configuring/core/monitors/) |
| **Biến môi trường** | `env = XMODIFIERS,@im=fcitx` | `hl.env("XMODIFIERS", "@im=fcitx")` | [Environment Variables Wiki](https://wiki.hypr.land/configuring/core/environment-variables/) |
| **Tùy chọn cấu hình** | `general { gaps_in = 5 ... }` | `hl.config({ general = { gaps_in = 5, ... } })` | [Config Options Wiki](https://wiki.hypr.land/configuring/core/config-options/) |
| **Màu viền cửa sổ** | `col.active_border = $col_pink` | `hl.config({ general = { col = { active_border = tokens.hypr.pink } } })` | [Config Options Wiki](https://wiki.hypr.land/configuring/core/config-options/) |
| **Đường cong Bezier** | `bezier = appleEase, 0.25, 1, 0.5, 1` | `hl.curve("appleEase", { type = "bezier", points = { {0.25, 1}, {0.5, 1} } })` | [Animations Wiki](https://wiki.hypr.land/configuring/core/animations/) |
| **Khai báo Animation** | `animation = windows, 1, 3, pop, popin 80%` | `hl.animation({ leaf = "windows", enabled = true, speed = 3, bezier = "pop", style = "popin 80%" })` | [Animations Wiki](https://wiki.hypr.land/configuring/core/animations/) |
| **Cử chỉ Touchpad** | `gestures { workspace_swipe = true }` | `hl.gesture({ fingers = 3, direction = "horizontal", action = "workspace" })` | [Gestures Wiki](https://wiki.hypr.land/configuring/core/binds/gestures/) |
| **Phím tắt có mô tả** | `bindd = $mainMod, SPACE, Tìm kiếm App, exec, rofi -show drun` | `hl.bind("SUPER + SPACE", hl.dsp.exec_cmd("rofi -show drun"), { description = "Tìm kiếm App" })` | [Binds](https://wiki.hypr.land/configuring/core/binds/) & [Flags](https://wiki.hypr.land/configuring/core/binds/flags/) |
| **Phím đa phương tiện** | `bindle = , XF86AudioRaiseVolume, exec, ...` | `hl.bind("XF86AudioRaiseVolume", hl.dsp.exec_cmd("..."), { locked = true, repeating = true, description = "..." })` | [Bind Flags Wiki](https://wiki.hypr.land/configuring/core/binds/flags/) |
| **Phím kéo/thả chuột** | `bindm = $mainMod, mouse:272, movewindow` | `hl.bind("SUPER + mouse:272", hl.dsp.window.drag(), { mouse = true })` | [Mouse Binds](https://wiki.hypr.land/configuring/core/binds/devices/mouse/) & [Issue #16850](https://github.com/hyprwm/Hyprland/discussions/16850) |
| **Submap Resize** | `submap = resize ... submap = reset` | `hl.define_submap("resize", function() ... end)` | [Submaps Wiki](https://wiki.hypr.land/configuring/core/binds/submaps/) |
| **Window Rule** | `windowrule = match:class ^(wall-picker)$, float on` | `hl.window_rule({ name = "wall-picker-float", match = { class = "^(wall-picker)$" }, float = true, size = { 1100, 700 }, center = true })` | [Window Rules Wiki](https://wiki.hypr.land/configuring/core/rules/window-rules/) |
| **Layer Rule** | `layerrule = match:namespace ^(waybar)$, blur on, ignore_alpha 0.1` | `hl.layer_rule({ name = "blur-waybar", match = { namespace = "^(waybar)$" }, blur = true, ignore_alpha = 0.1 })` | [Layer Rules Wiki](https://wiki.hypr.land/configuring/core/rules/layer-rules/) |
| **Workspace Rule** | `workspace = 1, monitor:eDP-1, default:true` | `hl.workspace_rule({ workspace = "1", monitor = "eDP-1", default = true })` | [Workspace Rules Wiki](https://wiki.hypr.land/configuring/core/rules/workspace-rules/) |
| **Khởi động cùng phiên** | `exec-once = waybar` | `hl.on("hyprland.start", function() hl.exec_cmd("...") end)` | [Autostart Wiki](https://wiki.hypr.land/configuring/core/autostart/) |

## 3. Các Lưu Ý Quan Trọng Khi Viết Lua Cho Hyprland 0.57.2

1. **Không kết hợp `{ mouse = true }` với `{ repeating = true }`, `{ locked = true }` hoặc `{ release = true }`**:
   - Trên Hyprland 0.57.x, `hl.bind` từ chối cờ `mouse = true` đi kèm các cờ `release`, `repeating`, `locked` hoặc `click` với lỗi `hl.bind: mouse is exclusive` ([GitHub Discussion #16850](https://github.com/hyprwm/Hyprland/discussions/16850)). Chỉ truyền `{ mouse = true }` cho các thao tác kéo/thả chuột (`hl.dsp.window.drag()`, `hl.dsp.window.resize()`).
2. **Cách gọi Dispatcher bên trong hàm callback Lua**:
   - Khi truyền trực tiếp vào `hl.bind(key, dispatcher)`, chỉ cần gọi `hl.dsp.window.close()`.
   - Khi viết hàm callback `hl.bind(key, function() ... end)`, bắt buộc phải bọc dispatcher bên trong `hl.dispatch(...)`, ví dụ: `hl.dispatch(hl.dsp.window.close())` ([Dispatchers Wiki](https://wiki.hypr.land/configuring/core/dispatchers/)).
3. **Không thực hiện tác vụ chặn (blocking I/O) trong callback của `hl.bind`**:
   - Tuyệt đối không dùng `io.popen`, `os.execute` hay `sleep` trong hàm callback của `hl.bind` vì chúng sẽ làm đứng luồng sự kiện của compositor. Thay vào đó, luôn dùng `hl.dsp.exec_cmd(...)` hoặc gọi script bất đồng bộ qua `hl.exec_cmd(...)` ([Lua Utilities Wiki](https://wiki.hypr.land/configuring/core/advanced-configuration/lua-utilities/)).
4. **Định dạng tham số `size` và `move` trong `hl.window_rule`**:
   - Theo [Window Rules Wiki](https://wiki.hypr.land/configuring/core/rules/window-rules/#position-and-size), `size` và `move` chỉ chấp nhận bảng Lua 2 phần tử (`size = { 1100, 700 }`) hoặc chuỗi phân tách bằng khoảng trắng (`size = "1100 700"`). Dùng dấu phẩy hay chữ `x` (`"1100x700"`) sẽ gây lỗi cấu hình.
5. **Tương thích `scripts/keyhints.sh`**:
   - Mọi phím tắt chính trong `config/hypr/modules/binds.lua` đều được gắn cờ `{ description = "..." }`. Nhờ đó lệnh `hyprctl binds -j` trả về đầy đủ trường `.description`, giúp `scripts/keyhints.sh` (`Super + F1`) hoạt động tự động 100% mà không cần parse file cấu hình tĩnh.
